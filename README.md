# Parallel Processing & Multiprocessor Architectures: Research and Benchmark

Research study with a Python benchmark comparing **sequential, multithreaded and multiprocess** execution of a CPU-heavy matrix-multiplication task.

*Group research project for IE2064 Advanced Computer Organization and Architecture, SLIIT.*

## Contents
- Literature review of parallelism techniques, bus structures and interconnection networks, performance analysis and design trade-offs
- `parallelism_module.py`: NumPy matrix workload run in three execution modes, with timing plotted using Matplotlib

## Run
```
pip install numpy matplotlib
python parallelism_module.py
```

## Tech
Python, NumPy, Matplotlib, multithreading, multiprocessing
